# Source-proved header blocks and blank fields

`native_header_registry.py` dispatches to configured proofs for reference/date metadata, literal unfilled form fields and repeated page headers. A failed proof never becomes a general column-gap waiver. All ordinary cell membership, outside-prose, number/operator, source-font, raster and registered-verifier gates still apply to the complete target page.

`native_blank_form_fields.json` contains the initial petitioner-name and integrated-mine-name label patterns. A qualifying row lies within the top quarter of its physical page and wholly above every independently proved source table. Its only right-hand content is actual underscore glyphs. Both original blocks are independently read, all glyph membership is retained, and a unique independent layout row must agree. The result stores the complete original source line, literal underscores, a null field value and unreviewed field semantics. It does not create a project or client fact. Filled values, numbers in the marker, other body labels, missing table proofs, changed cells, overlap and body-band rows fail.

`native_repeated_headers.json` limits the initial repeated-header rule to the top 8% of the page, two or three separated source blocks and a long uppercase publication heading. It requires one isolated edge page-number block and an independently matching header within four physical pages of the same original PDF. Printed-number differences must match physical-page differences; a fixed observed offset is allowed, but no printed literal is changed. Auxiliary section annotations remain exact source text. Geometry, font/glyph mapping, independent PDFium blocks, a unique pypdf layout row and paint visibility are checked on both pages. Operative text, short split clauses, body columns, inconsistent numbers, ambiguous rows and unresolved legacy fonts remain held.

A reference page contributes only its proved header blocks. Its body quality is never promoted. Every original header literal and source position stays in the proof and selected text. Neither rule deletes furniture, rewrites provisions, establishes semantic table headers, determines date effects or approves law.

The three initial real full-page trials (both requested mine-form examples and the repeated Gazette header) passed all eight source-quality gates plus fresh compact decoders under frozen b21. The broader correctly matched 12-page trial under frozen 86c3 passed nine pages and retained three holds. These are source-quality results, separate from legal review. The Powerlex evidence directories record exact original PDF/page hashes, source and proof epochs, positive and negative outcomes and registration deduplication.
