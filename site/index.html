Start locally

Small setup.
Useful output.

Node 20+ and uv are required for the npm launcher. Its first run prepares an isolated Python runtime. OCR and AI models are optional.

NPM LAUNCHER / RELEASE CANDIDATERelease ↗
  1. Install the launcher
    npm install -g https://github.com/rudraptpsingh/PDF2Data/releases/download/v0.2.0-rc.1/rudraptpsingh-pdf2data-0.2.0-rc.1.tgz
  2. Check your environment
    pdf2data doctor
  3. Open your local workspace
    pdf2data workspace --workspace ./documents

    Then open http://127.0.0.1:8771 in your browser.

Prefer Python? Get the wheel or source archive ↗
MCP / LOCAL STDIO

Install the launcher, run pdf2data-mcp --help once, then add this to your host’s MCP configuration. Replace the paths with your own.

{
  "mcpServers": {
    "pdf2data": {
      "command": "pdf2data-mcp",
      "args": [
        "--workspace", "/absolute/workspace",
        "--allow-dir", "/absolute/pdfs"
      ]
    }
  }
}
